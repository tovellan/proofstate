# ProofState 0.3.3

ProofState 0.3.3 constrains built wheel and source archives to an explicit,
reviewed file boundary.

## Changed

- Source archives contain only package source, build metadata, license, README,
  and the build ignore file.
- Wheel and source archive members are checked for unsafe paths, unexpected file
  types, missing reviewed files, and unreviewed additions.
- The PEP 561 `py.typed` marker is shipped for downstream type checkers.
- CI, local gates, and public releases all run the distribution boundary check.

Runtime behavior and schema identifiers are unchanged from 0.3.2.
