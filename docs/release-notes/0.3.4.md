# ProofState 0.3.4

ProofState 0.3.4 closes local Git indirection paths that could make verification
read a different object or path than the scorecard names.

## Security

- Git replacement refs are ignored for commit resolution, ancestry checks,
  tree identities, and blob reads.
- Git pathspec metacharacters in evidence paths are treated literally.
- Missing objects in partial clones fail locally instead of triggering a lazy
  fetch from a promisor remote.

The scorecard schema and result format are unchanged from 0.3.3.
