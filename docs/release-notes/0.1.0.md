# ProofState 0.1.0

ProofState 0.1.0 introduces fail-closed verification of repository readiness
scorecards against pinned Git trees.

The release includes file, pytest symbol, and structured artifact evidence;
scoped and expiring human attestations; dependency-aware assertions; explicit
gate caps; stable JSON results and error codes; and a complete synthetic example.

Known limitations are documented in the threat model. In particular, declared
attestation identities are not cryptographically authenticated, named tests are
not executed, and missing objects are not fetched from shallow clones.

The attached wheel and source archive are convenience artifacts. No package is
published to a package registry.
