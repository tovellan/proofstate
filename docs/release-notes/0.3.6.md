# ProofState 0.3.6

ProofState 0.3.6 corrects the complexity bound for structured object equality.

## Fixed

- Object comparisons now require exact key-set parity and recursively compare
  each value through one direct lookup.
- Reversed key insertion order no longer turns equality into a quadratic scan.
- A 30,000-key public artifact regression and direct-lookup count guard cover
  the near-input-boundary case.

Schemas, command behavior, and evidence results are unchanged from 0.3.5.
