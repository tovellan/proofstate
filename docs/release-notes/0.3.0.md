# ProofState 0.3.0

ProofState 0.3.0 lets independent implementations extract the portable
`v1alpha1` conformance inputs directly from an installed wheel.

## Added

- `proofstate conformance --export DIRECTORY` writes the exact manifest and all
  ten digest-pinned fixtures.
- Stable `PS012_CONFORMANCE_EXPORT_FAILED` JSON errors for unsafe or unavailable
  export destinations.
- Clean-wheel and public release checks exercise export as well as verification.

## Safety

Export verifies the complete installed bundle before creating output. It
requires an existing parent, refuses an existing destination, uses exclusive
file creation, and never deletes or replaces user data.

Scorecard evaluation and schema identifiers are unchanged from 0.2.1.
