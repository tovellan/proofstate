# ProofState 0.2.0

ProofState 0.2.0 makes the alpha document contract easier to implement and test
outside the reference Python package.

## Added

- An installed, digest-pinned `v1alpha1` conformance bundle with ten valid and
  fail-closed scorecard and attestation cases.
- `proofstate conformance` text and JSON output with per-case classifications.
- `proofstate schema attestation` alongside the existing scorecard JSON Schema.
- Clean-wheel conformance verification in CI and the release workflow.

## Compatibility

The scorecard, attestation, result, and error schema identifiers remain
`v1alpha1`. Evaluation behavior and exit statuses are unchanged. The existing
`proofstate schema` command still defaults to the scorecard schema.

ProofState remains local-only. It does not execute repository code, fetch remote
evidence, authenticate attestation identities, or publish a PyPI package.
