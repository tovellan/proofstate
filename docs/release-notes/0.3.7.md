# ProofState 0.3.7

ProofState 0.3.7 bounds remaining recursive and input-error paths and records
explicit build provenance for release distributions.

## Security

- Pytest symbol verification scans direct module definitions and direct methods
  in top-level classes without traversing function bodies or conditional suites.
- Dependency cycle validation and evaluation are iterative through the declared
  1,000-assertion limit.
- Conformance files are read only through the one MiB limit plus one byte.
- Release tags must identify the exact protected `main` dispatch commit.
- Wheel and source archive builds receive explicit GitHub and Sigstore
  provenance before immutable release creation.

## Fixed

- Unexpected Git failures in human attestation evidence return
  `PSE900_INTERNAL_ERROR` instead of escaping the evidence result.
- CLI syntax and choice failures honor requested JSON output with the versioned
  `PS001_INVALID_ARGUMENT` envelope.

Scorecard, attestation, result, error, and conformance schema identifiers are
unchanged from 0.3.6.
