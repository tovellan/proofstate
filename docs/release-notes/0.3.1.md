# ProofState 0.3.1

ProofState 0.3.1 updates the reviewed development type-checking toolchain to
mypy 2.x and its locked transitive dependencies.

The update passed the full Python 3.11 through 3.14 matrix, CodeQL, dependency
audit, clean-wheel installation, conformance verification and export, executable
example, repository policy checks, and full-history secret scanning.

Runtime dependencies, scorecard evaluation, public schemas, and the installed
conformance corpus are unchanged from 0.3.0.
