# ProofState 0.3.5

ProofState 0.3.5 makes the distribution boundary structural and byte-exact
before a public release can be created.

## Security

- Wheel and source archives reject duplicate names, unsafe paths, special
  entries, oversized members, and unreadable payloads.
- Wheels additionally reject encrypted or unsupported compression entries and
  require every CRC check to pass.
- Wheel `RECORD` must list every member exactly once with the correct SHA-256
  digest and size.
- Every packaged Python, JSON, and typing-marker byte must match the reviewed
  source tree in both distribution formats.
- YAML timestamp-looking scalars remain text until RFC 3339 schema validation,
  and non-string mapping keys fail closed.
- Nested structured comparisons distinguish booleans from numbers recursively.

## Release controls

- CI, local gates, and releases clean-install and exercise both the wheel and
  source archive.
- The release workflow refuses a tag whose commit is not present on `main`.

Runtime behavior and schema identifiers are unchanged from 0.3.4.
