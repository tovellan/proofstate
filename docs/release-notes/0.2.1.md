# ProofState 0.2.1

ProofState 0.2.1 hardens the public release boundary against mismatched or stale
version inputs.

## Changed

- Release jobs now require a plain semantic version and an annotated tag that
  identifies the exact checked-out commit.
- Project metadata, package metadata, release notes, wheel filename and metadata,
  and source archive metadata must all declare the same version.
- The local gate builds into an isolated temporary directory and rejects stale
  artifacts left by an earlier build.

Scorecard evaluation and the installed `v1alpha1` conformance corpus are
unchanged from 0.2.0.
