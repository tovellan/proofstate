# ProofState 0.3.2

ProofState 0.3.2 tightens fail-closed parsing and evidence matching for ambiguous
or resource-intensive inputs.

## Changed

- Reject non-finite numbers, nonstandard JSON constants, excessive document
  nesting, and oversized numeric JSON Pointer indexes.
- Reject repository paths containing empty or explicit dot segments.
- Require named pytest evidence to identify a top-level test function or a test
  method directly inside a `Test*` class.
- Apply exact type semantics to structured `contains` checks.
- Require timestamp strings to use the supported RFC 3339 shape.

Runtime dependencies and schema identifiers are unchanged.
